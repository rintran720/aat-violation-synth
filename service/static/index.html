How inputs are sorted

Put each frame in the folder of what it shows. A job uses only the folders of the engine you choose, and every case says which kinds it can turn into a violation. Results show each input frame with the outputs made from it.

  1. Give the frames as a zip of input-kind folders.
  2. Choose the engine and its output cases; check the outputs and tokens it will take.
  3. Generate: each chosen case makes one image per input frame, and they arrive beside their input one by one.
