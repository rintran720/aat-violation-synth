Object references

The image a case gives Astra after the frame, so it knows what an object looks like. Each object has ONE reference sheet: one image showing the object from several angles, and a text that says what it shows. A case picks its objects on the Engines page; its prompts name them as {ID}, numbered (image 2, 3, …) for each output.
