Prompts

Every text the Astra edit prompt is built from. A change applies to the next output made, in every project; each output's run folder keeps the exact prompt it got.

How a prompt is built

You are given N reference images from {setting}:
1. Full scene: {scene prefix}{input kind scene}.
2.. the output's references

{objects}

Edit image 1 only. Keep the SAME … viewpoint. {keep} …

Make this ONE change: {output change for the kind}
Choose an engine.

The engine's context: where the camera is and what its objects are. Every output of the engine gets it.

Input kind scenes

What image 1 shows, for each kind of input frame.

Output prompts

The ONE change each output makes, per input kind. Leave a kind empty and the output does not take frames of it. Name an object reference as {LSP}, {SKID}, …: each output numbers it (“image 2”, “image 3”, … in the order of the output's references). {lid_pose} is filled with a random floor-hatch cover angle per output.

References

What the prompt says each object reference shows; edit them and their images on the Object references page.
