Synthetic violation image pipeline (AAT)

Insert 3D-built LSPs and cargo into real camera frames that already contain a forklift, following the Forklift Pushing Multiple LSPs scenario. The pipeline has three stages, split by how often they run: A runs once and is shared by every camera; B runs once per camera; C runs automatically for every image.

A · Data & assets
Once, shared

Object samples, render assets, forklift fitting proxy, reference dimensions, scenario catalogue.

A. Data preparation, asset building and reference numbers

A1. Object samples cam01

What
SAM3 segments LSPs, cargo, SKIDs and forklifts; keeps the sharpest crops; normalises colour across cameras.
Output
work/refs/, work/masks/
Missing
Samples from several cameras, colour normalisation.

A2. Render assets Done

What
LSP, cargo (ULD, cartons) and SKID built in Blender through CLI-Anything, textured from real photos.
Code
synth/build_assets.py, blender/build_lsp.py
Output
work/assets/*.blend + size JSON

A3. Forklift fitting proxy Trial

What
Geometric model from the manufacturer's specs of each truck type, used to find the real truck's position and heading (not rendered).
cam01
Sumitomo QuaPro 2.0–2.5 t, dual front tyres: wheelbase 1625 mm, tread 1405/970 mm, fork face 477 mm from the front axle.

A4. Reference dimensions Partial

What
Standard sizes: LSP, ULD (AKE 1.56 × 1.53 × 1.63 m), truck specs. Used to build assets and check calibration.
Missing
A measured real LSP size.

A5. Scenario catalogue Done

What
V1–V8 violations (≥ 2 LSPs), N1–N5 valid and look-alike scenes; variation parameters.
Source
docs/superpowers/specs/, config.json

B. Per-camera context

B1. Camera & floor calibration Done

What
MoGe-2 on the background image gives the camera, the floor plane and an XYZ map of the floor.
Code
synth/calibrate.py → work/camera.json

B2. Checks against known objects Trial

What
Re-measure objects of known size; derive correction factors.
cam01
Floor plane within about ±5% in the centre; heights come out about 15–20% short, so they are corrected by ×0.85.

B3. Placement zone & exclusions To do

What
Floor area where objects may be placed; excludes the image border (large floor error), walkways and fixed occluders.

B4. Lighting & colour Partial

What
Ambient light, saturation, noise and lens distortion for compositing.
Source
work/scene_facts.json, the composite section of config.json

B5. Review render To do

What
One sample scene per camera, reviewed by a person before batch runs.

C. Automatic pipeline

C1. RTSP & frame filter Trial

What
Record video; SAM3 finds and tracks trucks; keep frames where the whole truck is visible, away from the border, large enough, preferably moving.
Run so far
10-minute cam01 video; 541/599 frames contain a truck; 150/150 consecutive frames tracked.

C2. Forklift pose & heading Trial

What
Silhouette fitting gives the position and the fork end; MoGe depth fixes the distance; the heading comes from the front-axle track while the truck moves.
Status
Position error about 0.05–0.3 m; silhouette heading off by about 8°, motion heading is better; about 1 s per frame.

C3. Place LSP & cargo Done

What
Place along the fork direction, LSP and cargo count per scenario; render in Blender.
Code
blender/render_anchor_poc.py
Missing
Free-space check (people or obstacles in the placement area).

C4. Occlusion Trial

What
Per-pixel depth comparison: cargo hides the truck; the truck and people hide the cargo; shadows are hidden too.
Status
Works on still images; not yet wired to per-frame MoGe on video.

C5. Composite & export Done

What
Composite into the original frame; export the image with JSON: event and per-object boxes, scenario, violation label, confidence.
Code
synth/composite_anchor_poc.py (with occluder_masks)

C6. Quality review To do

What
The machine logs metrics (fit IoU, reprojection error, occluded pixels); a person reviews a random share of the images.

Data passed between steps

Each step writes its output to its own files, so one step can be rerun without rerunning the whole chain.

Key findings on cam01

  • The trucks in the warehouse follow the Sumitomo QuaPro 2.0–2.5 t design, painted yellow, with dual front tyres (about 1.6 m wide). The old truck asset had wrong dimensions, so it is not used as an anchor.
  • The calibrated camera is correct on the floor but makes heights about 15–20% short; this is currently corrected by ×0.85.
  • The heading guessed from the silhouette is biased by about 8°; the heading from the truck's motion (front-axle centre) is more reliable.
  • Depth-based occlusion matches hand-drawn masks on the test images.
These numbers were checked on 3 still images and one video clip; no batch run yet.
